# Multi-Response Optimization and Robustness Analysis of Drilling Parameters for AA5083 Aluminum Alloy

Drilling AA5083 aluminum alloy requires controlling several hole-quality responses at once, yet most published optimization studies validate their models only on the data used to fit them. This study analyzes an 80-run full factorial drilling design (spindle speed, feed rate, tool diameter) with five responses: top and bottom burr thickness, circularity, cylindricity, and conicity error. Response surface models explain 13 to 28 percent of in-sample variance per response, but leave-one-out cross-validation shows this is optimistic: three of five responses score a negative predictive R2 (Q2). A Gaussian process model raises Q2 above zero for all five responses (0.035 to 0.184), though the values stay modest. Grey relational analysis and an independent TOPSIS ranking converge on the same short list of near-optimal parameter combinations, with a Spearman rank correlation of 0.92 between the two methods. The single combination built from each factor's individually best average level ranks only 26th to 31st of 80 tested combinations, because the effect of spindle speed reverses direction between small and large tool diameters. A 1,000-draw Monte Carlo noise simulation shows no single combination dominates: the most stable candidate lands in the top five only 37.7 percent of the time. These results point to a robust cluster of near-optimal drilling settings rather than one single winner.
